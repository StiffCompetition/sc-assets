# Gift Guide slides (holiday 2026)

Zero-cost carousel slides for the Gift Guide post type (Content Pipeline Playbook).
- slides/gg_<char>_1.jpg hook, _2 to _5 products (tee, mug, bottle, museum print), _6 call to action, _x the X image.
- slides/gg_mugs_1.jpg hook, _2 to _7 the six mugs, _8 call to action, _x the X image.
- src/ the shop's own product photos (1080 px) the slides are made from.
- scripts/ render.py and make.py (PIL, Anton font from Google Fonts, character art and bar from dtb/).
Run: put Anton-Regular.ttf in fonts/, the photos in src/, then python3 make.py.
